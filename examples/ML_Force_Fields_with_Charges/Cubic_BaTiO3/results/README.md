# Results

**Energy provenance gate (2026-09-13):** `qnep_export/train_qnep_249_sparse62.xyz`
and the earlier `cubic_104_*`/`cubic_301_*` training outputs are interface or
mixed-source audit artifacts, not valid final training data.  They must not be
used for reported accuracy or phonon figures.  The final model will be built
only after collecting the completed Wuzhen ABACUS/PBEsol SCF outputs verbatim;
no energy offset, shift, or normalization is allowed.  See
`docs/research/QNEP_ENERGY_PROVENANCE_CORRECTION_20260913.md`.

This directory contains small, provenance-preserving compatibility artifacts.
The public force-pool excerpt is retained only as a parser/interface fixture;
it is not part of the final force-field training data. The canonical training
set is the corrected, newly collected DFT-only cubic subset under
`qnep_training/dft_only_cubic_corrected_becpair_20260914/` dataset. The earlier
`dft_only_cubic_173.*` files are retained only as an audit of the two-BEC
assembly mistake. All corrected labels reuse completed Wuzhen ABACUS outputs;
no old DFT frame is rerun. `validation/` contains collection and schema
reports, while `qnep_export/` contains the earlier public-interface export for
regression tests.

The corrected final DFT-only JSONL contains 167 unique cubic frames: 117
primitive 5-atom finite-displacement rows and 50 completed 2x2x2 40-atom
frames. It contains 21 cubic BEC annotations: 19 unique primitive frames plus
the two unreduced 40-atom frames (`supp_003` and `supp_005`). All other frames
retain an explicit missing-BEC state. The two 40-atom responses used 120
forward displacements per parent (240 stages total); every polarization output
is present and no stage was recomputed after completion. All energy, force, and stress values are copied verbatim
from completed ABACUS/PBEsol calculations with the existing Wuzhen
pseudopotential/orbital setup. Every new DFT stage uses `kspacing=0.1` in
ABACUS INPUT, so ABACUS derives the mesh from that frame's cell; no fixed
primitive-cell mesh is imposed on the 2x2x2 supercell. The four geometrically
duplicated rows are recorded in the manifest and removed only after their raw
labels were checked for agreement.

Any earlier compact BEC-pair artifacts that contain a hand-authored `19x19x19`
PYATB mesh are legacy audit material and are excluded from the final merge.
The final pair uses the automatic `kspacing=0.1`/`pyatb_input --polar --mp 0.08`
workflow; the compact archive is retained outside the repository and only its
small collection manifests and two-frame annotation are checked in.

The 40-atom BEC workflow uses the installed `pyatb_input --polar --mp 0.08`
generator for every completed ABACUS frame. It derives the frame-specific
Fermi energy, occupied-band count, cell, matrix routes, and polarization mesh
automatically; no hand-written `nk1/nk2/nk3` template is used. The abandoned
manual-mesh experiment is retained only in the external run log.

`qnep_export/train_qnep_249_sparse62.xyz` is a legacy parser fixture: 249
unique structures after geometry de-duplication, 62 frames with validated
`(N,3,3)` BEC tensors, and 187 frames with explicit missing-BEC state.
`qnep_export/qnep_train_249_audit.json` records its qNEP parser check; it is
not used for the final DFT-only model.
The legacy public force pool contributes 250 source rows; 16 BEC-labelled
structures absent from that pool are appended, and duplicate geometries are
removed. Its energy/force records and mixed-label training run are retained
only for interface regression and provenance audit. A small cubic-only qNEP
training run is recorded under
`qnep_training/cubic_104_seed20260913/`: 83 training and 21 test frames with
16 and 4 BEC labels, respectively. It is a compatibility benchmark, not a
production qNEP model.

`figures/cubic_BaTiO3_BEC_coverage.{png,pdf}` is generated by
`run/plot_bec_coverage.py`. It shows the phase-resolved source order and the
explicit labelled/missing-BEC relation; the public excerpt has no per-frame
temperature metadata, which is stated on the plot rather than inferred.

`sample_dataset/qnep_bto_force_pool250.jsonl` is the 250-frame force-pool
excerpt selected from the public qNEP BaTiO₃ archive. The completed Wuzhen
campaign contains 65 parent families (48 primary + 17 add-on); 62 unique BEC
labels are merged into the 249-frame export and three failed/incomplete source
parents remain explicitly unlabeled. We do not replace missing BECs by zeros.
The primitive source provides phase labels but no reliable per-frame MD
temperature, so `temperature` remains unset rather than being fabricated.
The selected 40-atom P1 candidates use forward finite differences: ZStar
creates 3N=120 positive displacements per BEC frame; central differences (240)
are intentionally not used.  The final qNEP training split has 134 train and
33 test frames, with 18 and 3 BEC-labelled frames, respectively, and no
parent-family overlap.
The public archive does not provide per-frame MD temperatures, so the excerpt
records phase labels but leaves temperature unset. Its manifest keeps a public
source identifier rather than a machine-specific path.

The CPC panel (d) is a cubic-BaTiO₃ pair of phonon overlays: one compares DFT
and qNEP without NAC, and the other compares DFT and qNEP with NAC. Both use
the same Γ–X–M–Γ–R–X path. The no-NAC comparison measures short-range
force-field error, while the separate +NAC comparison shows the final result
after adding BEC/NAC. The machine-readable sidecar also records the NAC
increment diagnostic. GPUMD 5.7 supplies the trained-model finite-displacement forces and
equilibrium BEC; Phonopy applies NAC using the model BEC and the documented electronic dielectric scalar. The archived
`gpumd_phonon_8x8x8/` directory records the direct GPUMD `compute_phonon`
run, while the 40-atom displacement archive is used for the compact Phonopy
force-set/NAC overlay. Both curves use the same Γ–X–M–Γ–R–X path. The reported
frequency differences are an auditable small-model compatibility result, not
a production qNEP accuracy benchmark or a reproduction of qNEP Figure 5.
The corresponding held-out BEC parity plot is
`figures/cubic_BaTiO3_qNEP_BEC_parity.{png,pdf}`.
The final two-panel rendering is
`figures/cubic_BaTiO3_qNEP_final_n50_z05_10k_NAC_split.png`; the standalone
manuscript panels are
`figures/cubic_BaTiO3_qNEP_final_n50_z05_10k_without_NAC.{png,pdf}` and
`figures/cubic_BaTiO3_qNEP_final_n50_z05_10k_with_NAC.{png,pdf}`. Their
machine-readable sidecar is the matching `_NAC_split.json` file.

The current retraining is deliberately cost-capped to one A30 GPU and 10,000
generations (about 15 minutes).  The audited held-out metrics are 0.0288
eV/atom energy MAE, 0.2779 eV/A force MAE, and 0.0727 e BEC MAE.  The force
error is not production-level, so this run is retained as an interface and
phonon/NAC compatibility benchmark only.  No additional long GPU training or
finite-temperature MD is included in the CPC example without a separate
resource decision.

`validation/wz_bec_pilot_BEC.dat` and `wz_bec_pilot_response_fit.json` are a
small completed Wuzhen ABACUS/PYATB BEC-only pilot using the same PBEsol,
pseudopotential, orbital, cutoff, and k-point baseline as the existing ZStar
cubic-BaTiO3 case. It validates one cubic reference frame (three reduced
finite displacements); it must not be described as the planned 50--100-frame
campaign. Static dielectric/BORN files are intentionally absent because this
pilot exercised `zstar deal --pyatb --bec-only`.

The checked-in `validation/wz_bec_frame*_corrected_BEC.dat` files are small
initial examples from the campaign. The complete campaign result is summarized
by `validation/bec_campaign_final_manifest.json`; raw compact archives remain
outside the repository. Source frames use Ba/O/O/O/Ti order, while ABACUS
species blocks use Ba/Ti/O; the collector records and applies this explicit
permutation. The three incomplete source parents are not represented by zero or
placeholder BEC tensors.

The final compact campaign contains 612 reusable PBEsol SCF energy/force rows
from 65 complete BEC families. Only the neutral manifest
`validation/bec_force_only_final_manifest.json` is checked in; the JSONL rows
remain reproducible with `--force-only-output` and are kept off-repository
because their source paths point to Wuzhen scratch.
