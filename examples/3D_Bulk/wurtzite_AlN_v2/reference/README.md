# Literature reference

The primary comparison is Hoang *et al.* (2013), which reports PBEsol
piezoelectric and elastic tensors for wurtzite AlN under definitions aligned
with this benchmark: `e31=-0.618`, `e33=1.647`, `e15=-0.374 C/m2` and
`C11/C12/C13/C33/C44=397.0/145.6/114.2/376.9/114.4 GPa`.

The `d` comparison is secondary because the available aligned values
`d31=-2.1`, `d33=5.4`, `|d15|=2.9 pm/V` are GGA rather than PBEsol. See
`docs/v2_literature_sources.bib` and
`docs/v2_material_literature_comparison_20260916.md` for complete metadata,
DOIs, sign/handedness rules and the functional-priority policy.
