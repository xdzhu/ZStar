# CH4 HSE06/DZP replay

`BEC.raw.dat` is the unprojected position-matrix APT in the indexed ZStar
displacement-row convention. The mode tables and `spectra_result.json` were
produced after replaying existing ABACUS SCFs through the Unified molecular
response and PYATB static electronic-response path. No new DFT was performed.
See the parent README for the cube comparison, rotational drift and the limits
of this record. It does not contain the original SCF matrices or charge cubes.
