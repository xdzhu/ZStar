# MoS₂ structure used for the Figure 10 comparison

Both backends use the monolayer reconstructed from Table 1 of
[Ulian and Valdrè](https://doi.org/10.1107/S1600576723002571), with
a = 3.149 Å, c = 20 Å and a sulfur-plane separation of 3.137 Å.
The VASP reference input specifies the common geometry and sampling.
The archived ABACUS input is for the positive E′ Raman displacement,
with the same electronic settings as the other Raman displacements.

The VASP PAW datasets are Mo_sv and S, in POSCAR order. Obtain the matching POTCAR from your licensed VASP installation.
